# 🌍 AI-Powered Climate Resilience Predictor (India)

This project predicts climate risk indicators based on weather & pollution data using a Machine Learning model.

---

## 📦 Files in this Repository

- app.py → Streamlit app for prediction
- model.pkl → Trained ML model
- climate_risk_model.ipynb → Jupyter Notebook (source code: data preprocessing, training, saving model)
- dataset.csv → Dataset used for training
- requirements.txt → Required dependencies

---
